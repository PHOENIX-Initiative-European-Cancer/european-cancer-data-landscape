### Deep dive: FHIR

For the editors of the HL7 Europe Common Cancer Data Model (ECCDM) and the PHOENIX Initiative. Status 2026-11-18/19. This deepens the Germany section of `dach-benelux.md` (baseline: de.basisprofil.r4 1.6.0; MII KDS Onkologie 2026.0.3 and 2027.0.0-ballot; oBDS 3.0.5/3.1.0; terminology basics) and does not repeat it. Every bullet ends with its source; "n/f" = not found in a citable source. Repository facts were read with the GitHub API on 2026-11-18. Companion file: `germany-landscape.md` (registries, datasets, infrastructure, funding, people).

Headline findings for ECCDM editors:
- The MII KDS Onkologie module is the only maintained national oncology FHIR specification; its 2027 line (ballot 15.09.–27.10.2026, 98 StructureDefinitions, 121 ValueSets, 42 ConceptMaps) implements oBDS 3.0.x field numbering (XSD 3.0.5 as source), models TNM prefixes as modifierExtensions, synthesises TNM, and pins SNOMED CT International 20260701. It has no mCODE dependency and never had one (mCODE was only a commented-out dependency in the 2026 ballot config).
- Three ETL paths feed oBDS registry XML into those profiles: BZKF `obds-to-fhir` (Kafka, MII profiles 2026.0.3), DKFZ/samply `obds2fhir` (XSLT, DKTK model for the CCP Bridgehead) and a Lübeck openEHR pipeline. A reverse path (FHIR → oBDS XML via FML and Matchbox) exists in the BIH Senologie IG.
- There is no FHIR-based cancer-registry reporting, no ISiK oncology module, no KBV oncology MIO and no ePA oncology use case. The Modellvorhaben Genomsequenzierung (§ 64e) uses JSON Schema, not FHIR; MII provides a logical model and ConceptMap bridging to it.
- HL7 Germany stays on R4 (4.0.1); the TC FHIR position since 2023 is "R5 lesen, aber R4 nutzen", migration if any to R6, and the gematik KIG R6 workshop series was paused in June 2026 until EHDS makes R6 relevant. The HL7 Europe Base CI build does not reference the German base profiles.
- Terminology: no ICD-10-GM 2027 exists (three-year cycle, 2026 stays valid to 2028); oBDS 3.1.0 already carries ICD-O-4 and CTCAE 6.0 value lists; the German SNOMED CT edition had an extra 7th release in August 2026 (130,795 translated concepts); the BfArM ZTS serves 69 CodeSystems as NPM packages but no FHIR terminology operations; the MII Ontoserver is mTLS-gated.
