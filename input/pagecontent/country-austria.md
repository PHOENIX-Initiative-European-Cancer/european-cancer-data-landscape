### Austria (AT)

Region: DACH and Benelux. Sources: see the URLs on each statement; raw research reports in [sources/survey](https://github.com/PHOENIX-Initiative-European-Cancer/european-cancer-data-landscape/tree/main/sources/survey).

### FHIR guides, registry format and terminologies

1. **Base IG.** HL7 Austria FHIR Core IG. R5: `hl7.at.fhir.core.r5` 2.0.0, STU2, FHIR 5.0.0, generated 2025-01-24, current published; 2.1.0 (STU3) only as CI build. R4: `hl7.at.fhir.core.r4` 2.0.0, STU2, FHIR 4.0.1, generated 2025-01-27. Publisher HL7 Austria, TC FHIR. https://fhir.hl7.at/HL7-AT-FHIR-Core-R5/ ; https://fhir.hl7.at/HL7-AT-FHIR-Core-R4/ ; registry https://fhir.hl7.at/
2. **Oncology.** None. The HL7 Austria registry lists only Core R4/R5, TC-FHIR-AG-Scheduling-R5 and ELGA-AustrianPatientSummary-R4; ELGA is "mainly based on HL7 CDA" (https://fhir.hl7.at/ ; https://fhir.hl7.at/HL7-AT-FHIR-Core-R5/). Cancer registry FHIR profile set: not found.
3. **Registry standard.** Österreichisches Nationales Krebsregister, run by Statistik Austria under Krebsstatistikgesetz 1969 and Krebsstatistikverordnung 2019 (BGBl. II Nr. 124/2019). Hospitals must report exclusively electronically and structured via a secured interface provided by Statistik Austria, using the encrypted identifier vbPK-AS, within three months. Transmission channels: web form via eQuest, file upload via eQuest, or SFTP file transfer (Statistik Austria Standarddokumentation Krebsstatistik, §2.1.7, https://www.statistik.at/fileadmin/shared/QM/Standarddokumentationen/B_2/std_b_krebsstatistik.pdf); named XML/CSV schema: not found (verified 2026-11-19). https://www.statistik.at/statistiken/bevoelkerung-und-soziales/gesundheit/krebserkrankungen ; https://ris.bka.gv.at/Dokumente/BgblAuth/BGBLA_2019_II_124/BGBLA_2019_II_124.pdf ; https://www.statistik.at/fileadmin/publications/Krebserkrankungen_Berichtsjahr-2024_bf.pdf
4. **Terminologies.** SNOMED CT member since March 2019 (37th member), NRC ELGA GmbH; Austria Extension via SNOMED Managed Service, releases e.g. Nov 2025 (on Nov 2025 International Edition) and May 2026 (https://www.snomed.org/news/austria-introduces-nationwide-standard-of-clinical-terminology-with-membership-in-snomed-international ; https://conf.spaces.snomed.org/wiki/spaces/RMT/pages/353370146). ICD-10 BMSGPK 2026 in use since 01/2026; 2027 version registered (https://www.gesundheit.gv.at/OID_Frontend/oid-static/1/2/40/0/34/5/231.html). Registry coding: ICD-O-3 Revision 2 since 2020, TNM UICC 8th edition (Statistik Austria report above). LOINC: ELGA LOINC guideline V1.03 (2017), LOINC German Austria Edition 2.77 (https://www.elga.gv.at/fileadmin/user_upload/Dokumente_PDF_MP4/CDA/Leitfaden_LOINC_Anwendung_in_ELGA_V1.03.pdf). Drug coding: ELGA e-Medikation uses the Pharmazentralnummer (PZN) from the ASP-Liste plus ATC codes; the BASG keeps the register of authorised medicinal products (https://fhir.hl7.at/r4-ELGA-e-Medikation-main/StructureDefinition-at-elga-emed-medication-medikation-definitions.html) (verified 2026-11-19). Terminology server: TerminoloGit, https://termgit.elga.gv.at , ELGA GmbH, FHIR endpoint "FHIR-tx-at", replaced the old ELGA server on 1 Oct 2022 (https://www.gesundheit.gv.at/service/professional/it-services/terminologieserver.html).
5. **People.** TC FHIR authors page (dev build; the published 2.0.0 IG has no authors page and the dev page is not retrievable by automated fetch, checked 2026-11-19) names Anna Lin (TC FHIR Lead, FH OÖ), Reinhard Egelkraut (CGM), Oliver Krauss (FH OÖ) (https://dev-tergi.elga.gv.at/r5-core-70-Apply-Template-for-Base-IGs/authors.html); HL7 Austria chair Alexander Mense (https://hl7.eu/affiliate_at.html). Core R5 GitHub top contributors gabriel0316, oliver-krauss, regelkraut (https://github.com/HL7Austria/HL7-AT-FHIR-Core-R5). SNOMED NRC head Stefan Sabutsch (2019 press release above).

### Registries, public datasets, infrastructure and non-FHIR digital assets

#### (a) Cancer registries
- Population-based: Österreichisches Nationales Krebsregister, run by Statistik Austria since 1969, nationwide coverage (mandatory hospital reporting); ENCR members listed historically include Statistik Austria, Tyrol and Carinthia registries. https://www.statistik.at/statistiken/bevoelkerung-und-soziales/gesundheit/krebserkrankungen ; https://publications.iarc.fr/_publications/media/download/3789/c59f506329fb5e54d3a355edbb825388ed440e50.pdf
- Clinical/regional tumour registries: Tumorregister Tirol (1986), Vorarlberg (1981), Salzburg (1985), Kärnten (1988), Tumorzentrum Oberösterreich, Onkologisches Informationssystem; regional registries act as service providers for hospitals in most Länder (not Burgenland, Styria, Vienna). https://irihs.ihs.ac.at/id/eprint/6054/1/ihs-report-2021-stacherl-czypionka-hobodites-krankheitsverlaufsbezogene-krebsregister-oesterreich-europa.pdf ; https://epidownload.i-med.ac.at/download/public/ROeS/lectures/9_Analysis%20of%20Registries/Oberaigner_W.pdf
- Screening registries: breast cancer screening programme (national, since 2014) – the programme has a uniform documentation system with pseudonymised data routed via the Dachverband der Sozialversicherungsträger, a coordination office at ÖGK, GÖG evaluation (4th report 2014–2021, Oct 2023) and bPK-based linkage at Statistik Austria under § 15c GÖGG (https://www.parlament.gv.at/dokument/XXVIII/AB/1880/imfname_1701525.pdf ; https://www.sozialministerium.gv.at/Services/Aktuelles/Archiv-2024/evaluationsbericht-brustkrebs-frueherkennung.html ; https://www.jusline.at/gesetz/goegg/paragraf/15c.pdf) (verified 2026-11-19); no national organised colorectal programme (pilots Vienna, Styria, 2026). https://www.oesterreich.gv.at/themen/gesundheit/medizinische_versorgung/screening-programm_brustkrebs-frueherkennung.html ; https://www.salzburg24.at/news/oesterreich/salzburg-muss-warten-darmkrebs-screening-in-wien-und-steiermark-ausgerollt-art-327523
- Legal basis: Krebsstatistikgesetz 1969; Krebsstatistikverordnung 2019 (BGBl. II Nr. 124/2019). https://ris.bka.gv.at/Dokumente/BgblAuth/BGBLA_2019_II_124/BGBLA_2019_II_124.pdf
- Submission format: exclusively electronic, structured, via Statistik Austria's secured interface with vbPK-AS pseudonym, within 3 months; variable groups (diagnosis, TNM, other classifications) in the ordinance annex; schema name: n/f. Coding: ICD-O-3 Revision 2 since 2020, TNM UICC 8th edition. https://www.statistik.at/fileadmin/publications/Krebserkrankungen_Berichtsjahr-2024_bf.pdf
- Data access: via Statistik Austria request form; since January 2026 records pseudonymised with bPK-AS enabling linkage with other official statistics (e.g. employment and cancer study 2025). https://www.statistik.at/en/about-us/surveys/educational-cultural-research-and-health-institutions/cancer-registry-notification ; https://www.statistik.at/fileadmin/announcement/2026/01/20260129Krebsstatistik.pdf ; https://www.statistik.at/en/statistics/labour-market/labour-and-health/employment-and-cancer

#### (b) Public datasets
- Open statistics: STATcube and open.data Krebsstatistik (incidence, mortality, prevalence, survival from 1983). https://www.statistik.at/statistiken/bevoelkerung-und-soziales/gesundheit/krebserkrankungen
- Research microdata: Austrian Micro Data Center (AMDC) at Statistik Austria gives accredited institutions remote access to catalogued microdata; the Vorarlberg cancer registry operator aks Wissenschaft is AMDC-accredited until 2029; cancer registry dataset explicitly in the AMDC catalogue: n/f (https://www.statistik.at/en/services/tools/data-access/center-for-science/austrian-micro-data-center-amdc ; https://forschungsinfrastruktur.bmfwf.gv.at/en/fi/arbeitskreis-fur-sozial-und-praventivmedizin_5276) (verified 2026-11-19).
- ECIS: the Austrian national registry is in the ECIS list of contributing registries (100% coverage); Statistik Austria states ENCR and IACR membership and names ECIS as data user (https://ecis.jrc.ec.europa.eu/sites/default/files/2024-09/List_of_cancer_registries.pdf ; https://www.statistik.at/fileadmin/shared/QM/Standarddokumentationen/B_2/std_b_krebsstatistik.pdf) (verified 2026-11-19).
- Screening data, synthetic datasets, national data catalogue: n/f.

#### (c) Cancer infrastructure
- National plan: Nationales Krebsrahmenprogramm 2026–2035 (BMASGPK with Gesundheit Österreich GmbH), successor of 2014–2025 programme. https://www.sozialministerium.gv.at/Services/Aktuelles/archiv-2026/Nationales-Krebsrahmenprogramm-2026%E2%80%932035.html
