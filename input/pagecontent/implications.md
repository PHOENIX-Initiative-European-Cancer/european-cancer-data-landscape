### What the landscape means for ECCDM

1. **Seven countries have oncology FHIR artefacts** to align or map against: Germany (MII KDS Onkologie / oBDS), Switzerland (CH CRL), the Netherlands (IKNL NKR), Belgium (Belgian Cancer Registry on FHIR), France (INCa OSIRIS and the PSCC pilot profiles) and, at draft level, Estonia (VJL) and Lithuania (screening guides). Only two touch mCODE (the NHS Genomics guide as a dependency, OSIRIS through radiotherapy value sets); none builds on it. This supports the mCODE decoupling already done in ECCDM.
2. **Registry data standards dominate.** Where oncology FHIR exists it wraps a registry dataset (oBDS, KRG, NKR item set, Bijlage 55). ECCDM's logical models map most naturally onto these registry datasets, and the ENCR variable set is the common denominator for the twenty-plus countries without oncology FHIR work.
3. **SNOMED CT coverage is not universal.** Italy, Poland, Romania, Bulgaria and Greece are not members; Latvia and Hungary joined between 2024 and 2026 and have no national content yet. ECCDM bindings that are SNOMED-only need an ICD-O-3 or ICD-10 fallback, or example strength, for these jurisdictions.
4. **ICD-O-3 is the one oncology code system in use everywhere**, but editions differ: 3.1 in older registries, 3.2 in Spain, Sweden, Czechia, Slovakia and Ireland (adopted 2020 to 2026), Germany's 2019 revision, and ICD-O-4 (2026) already scheduled in oBDS from April 2027. ECCDM should state the ICD-O edition in its bindings.
5. **TNM edition is in transition.** Most registries still code UICC 8; Germany (oBDS 3.0.5), Czechia (NOR from 2027), Slovakia (2026 guidance) and France (UICC 9 effective 2026) are moving to TNM 9. The CancerStage model should carry the edition explicitly.
6. **LOINC is thin outside DACH, Benelux and the Nordics.** National LOINC variants exist for DE, AT, NL, FR, IT, ES, PL and EE; the UK uses the SNOMED Unified Test List; the Nordics use NPU. Observation-type bindings in ECCDM should not assume LOINC availability.
7. **FHIR release split.** R4 is established everywhere with a mature guide (DE, CH, NL, BE, FR, UK, DK, SE, NO, FI, CZ, HR); R5 appears in the newer guides aligned with HL7 Europe Base R5 (AT, EE, LT, PL, GR, and the Spanish UNICAS guide). ECCDM is published on FHIR 4.0.1 with cross-version extensions, which matches the established guides; an R5 rendering would match the newer ones.
8. **National core alignment is moving to HL7 Europe Base.** France's FR Core 3.0.0-ballot (November 2026) and Czechia's CZ Core 1.0.0 depend on HL7 Europe Base 2.0.0; Greece's draft depends on the R5 base. ECCDM's own dependency on HL7 Europe Base 2.0.0 is therefore the right anchor for patient, organisation and practitioner profiles.
