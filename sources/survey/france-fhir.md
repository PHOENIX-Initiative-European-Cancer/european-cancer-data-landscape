## 1. OSIRIS

### 1.1 Identity, minimum data set, versions

- **Name**: OSIRIS = "GrOupe inter-SIRIC sur le paRtage et l'Intégration des donnéeS clinico-biologiques en cancérologie" (inter-SIRIC task force for clinical and biological data sharing and interoperability in oncology). Launched 2015 by INCa. — https://github.com/siric-osiris/OSIRIS (README); https://health-data-hub.fr/sites/default/files/2025-01/osiris%20%281%29%20%281%29.pdf (Health Data Hub standard sheet, 24 p., 2025-01).
- **Minimum data set size**: 132 Common Data Elements = 67 clinical + 65 omics items; event-based model centred on the TumorPathologyEvent (TPE). — https://pmc.ncbi.nlm.nih.gov/articles/PMC8140800/ ; HDH sheet above.
- **Reference publication**: Guérin J, Laizet Y, Le Texier V, Chanas L, Rance B, Koeppel F, Lion F, Gourgou S, Martin AL, Tejeda M, Toulmonde M, Cox S, Hess E, Rousseau-Tsangaris M, Jouhet V, Saintigny P. "OSIRIS: A Minimum Data Set for Data Sharing and Interoperability in Oncology." JCO Clin Cancer Inform 2021;5:256-265. **DOI 10.1200/CCI.20.00094**, PMID 33720747, PMC8140800. Proof of concept on 300 patients from 6 molecular-profiling trials; supplement 3 compares OSIRIS with mCODE and OMOP-CDM. — https://pmc.ncbi.nlm.nih.gov/articles/PMC8140800/ ; HAL copy https://hal-bioemco.ccsd.cnrs.fr/CURIE/hal-03203166v1 ; supplement https://ascopubs.org/doi/suppl/10.1200/CCI.20.00094
- **Version history of the data framework (siric-osiris/OSIRIS, "OSIRIS Core / OSIRIS-CT")**:
  - v1.0 2018-05-04; v1.1.03 2018-09-07; v1.1.04 2018-12-04; v1.1.05 2019-02-06 (GitHub releases). Repo last pushed 2023-03-08, 20 stars; pivot CSVs for 18 tables (Patient, TumorPathologyEvent, TNM, Treatment, Drug, AdverseEvent, Analysis, Variant, …). — https://github.com/siric-osiris/OSIRIS/releases ; https://github.com/siric-osiris/OSIRIS/tree/master/pivot
  - "OSIRIS CT 2021" (clinical-trials model: conceptual, logical, physical model, PostgreSQL DDL, terminology list) is the official version in INCa's repo **OSIRIS_OFFICIEL** (created 2023-03-29, last push 2025-04-08, CC BY-SA 4.0; contact osiris@institutcancer.fr, +33 1 41 10 72 11). HDH sheet says OSIRIS Core was "the only version published, May 2023", with OSIRIS RWE and OSIRIS Lung then in preparation. — https://github.com/InstitutNationalduCancer/OSIRIS_OFFICIEL ; HDH sheet p.3-4.
  - Sub-module repos under INCa: OSIRIS_Clinique (2025-04-03), OSIRIS_Genomic (2024-04-09), OSIRIS_Radiotherapy (2024-08-05, dictionary "2023 Radiothérapie"), OSIRIS_Radiomics (2024-08-05), UseCase_and_Results, Usagi_for_OSIRIS (OMOP mapping tool), JupyterNotebook_for_OSIRIS, IG-template. — https://github.com/orgs/InstitutNationalduCancer/repositories
  - Terminology list of OSIRIS-CT 2021 (file `Terminologiessanté_OSIRISCT_2021_FR.md`): ATC 2023-01, CCAM v73, CIM-10 (ATIH 2023-05-04), FINESS, LOINC Bio FR 2.15, MedDRA 24.1, NCIt 22.12d, SNOMED CT International Dec 2023, **TNM "v8" (UICC)**, UCUM 2.1. — https://github.com/InstitutNationalduCancer/OSIRIS_OFFICIEL
- **OSIRIS RWD (real-world data) — the active 2026 line**: repo **OSIRIS_WG_OSIRIS-RWD** ("groupe de travail données de vie réelle"), created 2026-01-20. Releases: v1.0.0 2026-03-30 ("validation ongoing"), **v2.0.0 2026-06-10** (27 tables, 114 variables, 73 mandatory; MDS xlsx, population guide, physical model, changelog, REDCap data dictionary), **v3.0.0 2026-09-04** (27 tables, 126 columns, breaking changes). "An INCa project, coordinated with the support of Unicancer"; CC BY-SA 4.0; publication "forthcoming". Contributors: ebensadon-unicancer, jhuyard-unicancer (Julien Huyard, Unicancer), INCaIFernandez (Isabelle Fernandez, INCa). Terminologies: **ICD-O-3.2** (topography and morphology), ICD-10, ATC, CCAM, LOINC, SNOMED CT, NCIt, HGNC, UniProt, UCUM, DICOM, FINESS, ENCR; dates split day/month/year; `Metadata` table for provenance incl. ### 1.8 IG value sets inspected (FSH files, repo master, 2025-04)

Source files: https://github.com/InstitutNationalduCancer/ImplementationGuide_OsirisFHIR/tree/master/input/fsh

- **VS_TNMVersion.fsh**: only three codes from the OSIRIS code system (`https://github.com/siric-osiris/OSIRIS`, alias OSIRIS; CS_Osiris.fsh canonical `https://terminology.arkhn.com/osiris`): C27-1 "5th edition", C27-2 "6th edition", C27-3 "7th edition". **UICC 8th edition is absent** (although OSIRIS-CT 2021 terminology list says "TNM v8" and OSIRIS-RWD discusses UICC 8/9 via SNOMED). — .../VS_TNMVersion.fsh ; .../CS_Osiris.fsh
- **OncoTNM profile** (SD_OncoObservations.fsh): Observation, code UMLS#C1515169 "TNM Staging System"; components tnm-t LOINC 21905-5, tnm-n 21906-3, tnm-m 21907-1 (all `valueString`), tnm-type LOINC 75620-5 (CodeableConcept; TNM version carried in `coding.version`). No stage-group element. PerformanceStatus: code UMLS#C0451140 (ECOG), valueInteger. — .../SD_OncoObservations.fsh
- **VS_Morphology.fsh**: 1 032 explicit ICD-O-3 morphology codes, system `http://terminology.hl7.org/CodeSystem/icd-o-3` (alias ICDO3), no version stated; content corresponds to the ICD-O-3 first revision (2011/2013) code list (e.g. 8013/3, 8014/3, 8015/3 present; no 3.2-only additions checked present). — .../VS_Morphology.fsh
- **VS_Topography.fsh**: ~400 ICD-O-3 topography codes C00–C80 (3- and 4-character), same system, no version. — .../VS_Topography.fsh
- **TumorPathologyEvent** (Condition): code from TumorPathologyEventType (UMLS: Neoplasm, Metastatic, Recurrent, Primary, Unknown); bodySite from Topography (extensible); morphology carried as a `stage` slice (type code UMLS#116676008, summary from Morphology); extensions laterality (UMLS codes), histology grade, due-to (parent TPE). — .../SD_TumorPathologyEvent.fsh ; .../VS_Clinical.fsh
